# ADR-0001: 原作形式マップの表示用翻訳をsidecarで管理する

**Status:** Accepted

**Date:** 2026-09-13

**Deciders:** 開発者

## Context

MP2/MX2のマップ名と説明文はマップファイルに固定長で埋め込まれ、gettextを通らない。
正本値を書き換えると、セーブデータ、ハイスコア、スクリーンショット名、マップ選択状態などへ影響する。
ファイル名だけ、または原文だけの照合では、同名のユーザーマップへ訳を誤適用する可能性がある。

## Decision

- `feature/cjk-support`を基点とする専用ブランチで、機構と初回の翻訳データを一体として実装する。レビューと差し戻しの単位を既存のCJK対応から分離できるためである。
- UTF-8のタブ区切りsidecarを`files/lang/<言語>.map-translation.tsv`へ置く。現行97枚の原文にはタブと改行がなく、差分の確認や行追加を簡単に保てるためである。
- `ファイル名＋原文名＋原文説明`の完全一致をキーとする。
- MP2/MX2の正本値は変更せず、シナリオ選択、ゲーム設定、ゲーム情報、セーブ情報の各画面で描画する直前だけ訳文を解決する。
- 現在のUI言語に対応する訳がない場合や複合キーが一致しない場合は原文を表示し、不一致をマップごとに一度ログへ残す。

## Options Considered

### MP2/MX2を直接編集する

固定長制約、原本破損、他言語への切替不能、原作資産の再配布という問題があるため採用しない。

### 動的なgettext検索だけを使う

ユーザーマップの同一原文にも訳を適用し、通常の抽出処理もmsgidを発見できないため採用しない。

### ファイル内容のハッシュをキーにする

誤適用には強いが、販売版や軽微な改訂ごとに別ハッシュが必要になる。初版では可読な複合キーを採用し、必要になった時点で複数識別子を検討する。

## Consequences

- 翻訳追加はsidecarの行追加だけで行え、マップ本体やC++コードを変更しない。
- 原文の句読点を含む完全一致なので、未知の版には安全側へ倒して訳を適用しない。
- sidecarは配布物へ含める必要があり、各プラットフォームの資産コピー設定を保守する。
